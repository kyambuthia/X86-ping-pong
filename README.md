# X86 Ping-Pong

A client and server that exchange ping-pong messages over a network socket,
written in x86 assembly.

## Project goals

- Implement the server in x86 assembly.
- Implement the client in x86 assembly.
- Use the platform's socket system calls directly where practical.
- Keep the wire protocol small and easy to inspect while learning low-level
  networking.

## Planned layout

```text
server/   Server implementation
client/   Client implementation
```

## Status

This repository is initialized as the starting point for the x86 assembly
server/client implementation.
